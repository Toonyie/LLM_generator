### 1. Prerequisites (Do these before testing)

* **Python 3.8+**
* **Gemini API Key:** You must have a key from [Google AI Studio](https://ai.google.dev/).

### 2. Installation

Install the official Google GenAI SDK for Python:

```bash
pip install google-genai
```
### System requirements
- Windows
- One of:
  - MinGW-w64 (gcc in PATH), or
  - Visual Studio Build Tools (cl.exe in Dev Prompt)
